Este documento contiene TODO lo relativo al proyecto de
gestión de horarios del equipo de cocina de Attica As Galeras.
Es un proyecto independiente dentro del ecosistema Fredware.

════════════════════════════════════════════════════════════
🎯 VISIÓN DEL PROYECTO
════════════════════════════════════════════════════════════

Crear una aplicación web que permita al jefe de cocina:
  · Elaborar los horarios semanales de forma visual
  · Detectar conflictos automáticamente (horas extras,
    libranzas sin 2 días consecutivos, restricciones)
  · Gestionar el banco de horas (L.r / F.r / extras)
  · Gestionar vacaciones, bajas y festivos
  · Clasificar eventos/grupos/cócteles con personas
  · Imprimir los horarios en A4 horizontal
  · Que los cocineros vean su horario desde el móvil

Estructura de datos:
  · Supabase como backend (online, compartido)
  · Turnos ya catalogados (M0-M7, T1-T5, P1-P7 + especiales)
  · Empleados con estados (activo/baja/vacación/fijo disc.)
  · Semanas guardadas en JSONB (asignaciones + eventos)
  · Banco de horas separado para L.r / F.r
  · Ausencias registradas con fechas de inicio/fin

TABLAS SUPABASE:
────────────────────────────────────────────────────────────

· horarios_turnos
  codigo (PK), nombre, hora_inicio, hora_fin,
  hora_inicio_2, hora_fin_2, horas_totales, tipo, orden, activo

· horarios_empleados
  id (PK), nombre (UNIQUE), puesto, tipo_personal,
  turno_preferido, solo_manana, solo_tarde, solo_partido,
  horas_semanales (default 40), activo, estado, orden, notas,
  created_at, updated_at

· horarios_ausencias
  id (PK), empleado_id (FK), tipo, fecha_inicio, fecha_fin,
  notas, created_at
  → Tipos: BAJA | VACACIONES | FESTIVO | ASUNTOS_PROPIOS

· horarios_semanas
  id (PK), año, numero_semana, fecha_inicio, fecha_fin,
  asignaciones (JSONB), necesidades (JSONB), eventos (JSONB),
  notas, estado, created_at, updated_at
  UNIQUE(año, numero_semana)

· horarios_banco_horas
  id (PK), empleado_id (FK), tipo, fecha_original, horas,
  motivo, fecha_compensada, compensado_por, estado, notas,
  created_at
  → Tipos: LR | FR | EXTRA
  → Estados: PENDIENTE | COMPENSADO | CANCELADO

🎯 CICLO PICA — DETALLE
════════════════════════════════════════════════════════════

Especial rotación de los 2 pica (Daniel y Matias).

**Semana A (ISO impar):**
| Día | Daniel | Matias |
|-----|--------|--------|
| Lun | L      | P2     |
| Mar | L      | P2     |
| Mié | P2     | L      |
| Jue | P2     | L      |
| Vie | M3     | T1     |
| Sáb | M3     | T1     |
| Dom | M3     | T1     |

**Semana B (ISO par): invertido**
| Día | Daniel | Matias |
|-----|--------|--------|
| Lun | P2     | L      |
| Mar | P2     | L      |
| Mié | L      | P2     |
| Jue | L      | P2     |
| Vie | T1     | M3     |
| Sáb | T1     | M3     |
| Dom | T1     | M3     |

La app detecta la semana (par/impar) y aplica el ciclo
automáticamente con el botón "🔄 Aplicar rotación".

Después se puede ajustar a mano (ej: si libran un fin de
semana porque no hay carga).

Si un pica libra un fin de semana, se le pega el lunes y
martes siguiente. Eso lo hace el jefe manualmente.

════════════════════════════════════════════════════════════
📅 TIPOS DE EVENTO (CLASIFICACIÓN)
════════════════════════════════════════════════════════════

3 categorías con 8 tipos:

GRUPOS (🟡 punto amarillo):
  · grupo_desayuno    → 🥐 Grupo desayuno
  · grupo_almuerzo    → 🍽️ Grupo almuerzo
  · grupo_cena        → 🌙 Grupo cena

EVENTOS (🩷 punto rosa):
  · evento_almuerzo   → 🎉 Evento almuerzo
  · evento_cena       → 🎉 Evento cena

CÓCTELES (🟣 punto morado):
  · coctel_manana     → 🍸 Cóctel mañana
  · coctel_tarde      → 🍸 Cóctel tarde
  · coctel_noche      → 🍸 Cóctel noche

Cada día puede tener varios tipos a la vez (ej: sábado
con grupo almuerzo 78 + evento cena 12 + cóctel tarde 45).

La fila TOTAL calcula la suma de personas por día y la
destaca en rojo si supera 50.
