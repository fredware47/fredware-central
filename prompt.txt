════════════════════════════════════════════════════════════
🎯 VISIÓN GENERAL DEL PROYECTO
════════════════════════════════════════════════════════════

Fredware es un ecosistema de aplicaciones HTML + backend Python +
Supabase para gestionar cocina, almacén y compras del restaurante
Attica As Galeras.

El objetivo final es crear un sistema que fusione lo mejor de:
  · MarketMan      → gestión de inventario, pedidos, proveedores
  · Apicbase       → recetas, costes, escandallos, producción
  · Leanpath       → medición y prevención de mermas

Pero hecho a medida, sin costes de licencia, integrado con
el hardware existente (Brother QL-810W, ngrok, backend Python)
y adaptado al flujo real de la cocina (timbres, baldas, etc.).

         Etiqueta → Stock → Dashboard
