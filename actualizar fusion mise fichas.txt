🎯 OBJETIVO
──────────
Cuando desde `miseandplace.html` un cocinero imprima una etiqueta de
ELABORACIÓN (botón 🏷️ → modal → IMPRIMIR), la app debe:

  1. Guardar la etiqueta en `etiquetas_rapidas`          (✓ ya funciona)
  2. Descontar stock si el item tiene `producto_racion_id`(✓ ya funciona)
  3. 🆕 Actualizar la ficha de producción en `fichas`:
        · Buscar ficha por nombre del producto (ILIKE exacto)
        · Refrescar fechas de llegada de cada ingrediente
          con la última recepción real de `recepciones`
        · Actualizar `lote`, `fecha_preparacion`,
          `fecha_llegada_ingredientes` e `ingredientes_detalle`

· ❌ NO duplicar el modal ni refactorizarlo
· ❌ NO tocar el flujo de descongelación (no actualiza ficha, no descuenta)
· ❌ NO crear tablas ni columnas nuevas

🔍 VERIFICACIÓN DE NOMBRES (paso crítico)
──────────────────────────────────────────
Antes de activar la auto-actualización, verificar que los nombres
de items del catálogo (timbres_catalogo.item_nombre) COINCIDEN con
los nombres de fichas (fichas.nombre_produccion).

Query de verificación:

   ┌───────────────────────────────────────────────────────┐
   │ SELECT DISTINCT                                       │
   │   c.item_nombre AS item_catalogo,                     │
   │   f.nombre_produccion AS ficha_asociada               │
   │ FROM timbres_catalogo c                               │
   │ LEFT JOIN fichas f                                    │
   │   ON f.nombre_produccion ILIKE c.item_nombre          │
   │ WHERE c.activo = true                                 │
   │   AND c.item_bold = false                             │
   │ ORDER BY f.fecha_preparacion DESC NULLS LAST;         │
   └───────────────────────────────────────────────────────┘

Items con `ficha_asociada = NULL` → no actualizarán nada (normal).
Items con match → se actualizarán al imprimir.

Si hay MUCHOS items sin match pero que SÍ tienen ficha, revisar:
· Diferencias de nombre (acentos, mayúsculas, singular/plural)
· Considerar crear un campo `ficha_id` en timbres_catalogo para
  vincular explícitamente en vez de depender del nombre.

────────────────────────────────────────────────────────────
async actualizarFichaDesdeEtiqueta(producto, lote, fechaOrigenDate, tipo) {
    try {
        const { data: fichas, error } = await this.supabase
            .from('fichas')
            .select('*')
            .ilike('nombre_produccion', producto)
            .order('created_at', { ascending: false })
            .limit(1);

        if (error) throw error;

        if (!fichas || fichas.length === 0) {
            return { actualizada: false, motivo: 'sin_ficha' };
        }

        const ficha = fichas[0];

        const { data: recepciones } = await this.supabase
            .from('recepciones')
            .select('producto, proveedor, fecha_recibido, fecha_registro')
            .order('fecha_recibido', { ascending: false })
            .limit(1000);

        const recepList = recepciones || [];

        const lineas = (ficha.ingredientes_detalle || '')
            .split('\n')
            .filter(l => l.trim());

        const nuevosIngredientes = lineas.map(linea => {
            const limpia = linea.replace(/^•\s*/, '').trim();
            const match = limpia.match(
                /^(.+?)\s*\(Lote Prov:\s*(.+?)\)\s*-\s*Llegada:\s*(.+)$/i
            );

            let prod, prov, fechaAnt;
            if (match) {
                prod = match[1].trim();
                prov = match[2].trim();
                fechaAnt = match[3].trim();
            } else {
                prod = limpia;
                prov = 'S/P';
                fechaAnt = 'S/F';
            }

            const recep = recepList.find(r =>
                r.producto &&
                r.producto.toUpperCase().includes(prod.toUpperCase())
            );

            if (recep) {
                const fechaRec = recep.fecha_recibido || recep.fecha_registro;
                const fechaNueva = this.formatDate(new Date(fechaRec));
                const dAnt = this.parseDDMMYYYY(fechaAnt);
                const dNue = new Date(fechaRec);
                if (!dAnt || dNue > dAnt) {
                    return `• ${prod} (Lote Prov: ${recep.proveedor || prov}) - Llegada: ${fechaNueva}`;
                }
            }

            return `• ${prod} (Lote Prov: ${prov}) - Llegada: ${fechaAnt}`;
        });

        const fechaISO = fechaOrigenDate.toISOString().split('T')[0];
        const { error: errUpd } = await this.supabase
            .from('fichas')
            .update({
                lote: lote,
                fecha_preparacion: fechaISO,
                fecha_llegada_ingredientes: fechaISO,
                ingredientes_detalle: nuevosIngredientes.join('\n')
            })
            .eq('id', ficha.id);

        if (errUpd) throw errUpd;

        return {
            actualizada: true,
            ficha_nombre: ficha.nombre_produccion
        };
    } catch (e) {
        console.error('❌ Error actualizando ficha:', e);
        return { actualizada: false, motivo: e.message };
    }
}

formatDate(fechaStr) {
    if (!fechaStr) return 'S/F';
    const d = new Date(fechaStr);
    if (isNaN(d)) return fechaStr;
    return `${String(d.getDate()).padStart(2,'0')}/` +
           `${String(d.getMonth()+1).padStart(2,'0')}/` +
           `${d.getFullYear()}`;
},

parseDDMMYYYY(str) {
    if (!str || str === 'S/F' || str === 'S/L') return null;
    const parts = String(str).split('/');
    if (parts.length !== 3) return null;
    const d = new Date(
        parseInt(parts[2]),
        parseInt(parts[1]) - 1,
        parseInt(parts[0])
    );
    return isNaN(d) ? null : d;
}
